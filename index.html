Informasi Sistem

Sistem informasi ini dibuat menggunakan HTML untuk menampilkan data mahasiswa.

Fitur Tambah Mahasiswa

Fitur tambah mahasiswa memungkinkan pengguna untuk menambahkan data mahasiswa baru ke dalam sistem. Pengguna dapat mengisi formulir dengan informasi mahasiswa seperti nama, NIM, jurusan, dan email. Setelah data diinputkan, sistem akan menyimpan data tersebut dan menampilkannya dalam daftar mahasiswa.
